# 開発の始め方

このサイトの開発手順。初めての人は上から順にやれば作業に入れる。

## 1. 用意するもの

- Git
- Node.js 24 系（リポジトリ直下の `.node-version` が正。nvm / fnm 等で合わせる）
- npm（Node に付属）

## 2. ローカルで動かす

```bash
git clone https://github.com/hayato-0510/graduation-live-2027.git
cd graduation-live-2027
npm ci
npm run dev
```

ブラウザで http://localhost:4321 を開くとサイトが見える。
ファイルを保存すると自動で再読み込みされる。

その他のコマンド:

| コマンド          | 意味                              |
| ----------------- | --------------------------------- |
| `npm run check`   | 型と文法のチェック（CI でも走る） |
| `npm run build`   | 本番用にビルド（CI でも走る）     |
| `npm run preview` | ビルドした結果をローカルで確認    |

## 3. 作業の流れ

Issue を取る → dev からブランチを切る → 変更する → ローカルで確認 → Pull Request（dev 宛て）→ プレビューで確認 → レビュー → dev にマージ。本番へは昇格 PR で出す。
詳しい行程は [workflow.md](workflow.md)、ブランチの名前や扱いは [branch-rules.md](branch-rules.md)。

## 4. 作業の段階

| 段階  | 内容                                                    | 例                                 |
| ----- | ------------------------------------------------------- | ---------------------------------- |
| 段階1 | `src/data/` の JSON、文章、画像の差し替え               | バンド名の追加、紹介文の修正       |
| 段階2 | 既存コンポーネントのコピーと軽い改変                    | カードの色変更、項目の追加         |
| 段階3 | 共通部品（レイアウト、全体CSS、ヘッダー、データの形式） | やる前に主催者へ一言。レビュー必須 |

## 5. やってはいけないこと

- main や dev へ直接 push する（ブランチ保護で弾かれるが、試みない）
- JSON の形式（キー名や構造）を勝手に変える（段階3の作業）
- 決まっていない情報（時間、会費、住所など）を推測で書く。未定のものは「未定」と表示するのがこのサイトの約束

## 6. 困ったら

- CI が赤い: PR の Checks から失敗したログを見る。`astro check` のエラーはファイル名と行が出る
- プレビューが開けない: デプロイに数分かかる。少し待ってから再読み込み
- 分からない: PR のコメントで聞く。作業途中の PR を Draft で出しておくのも可
